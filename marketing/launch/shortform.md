# 쇼츠 · 릴스 대본 (30초 내외)

> 화면: 휴대폰으로 사이트를 켜고 숫자를 입력하는 화면 녹화 + 자막. 얼굴이나 목소리 없이 자막만으로도 충분해요.

## 1. "연봉 4천, 통장엔 얼마?"
| 시간 | 화면 | 자막 |
|---|---|---|
| 0~3초 | 연봉 입력칸 클로즈업 | 연봉 4천이면 한 달에 얼마 받을까? |
| 3~8초 | 40,000,000 입력 | 333만원? 아니에요 |
| 8~15초 | 결과 291만원 확대 | 실제로는 약 291만원 |
| 15~24초 | 공제 내역 스크롤 | 국민연금 14만9천, 건강보험 11만3천, 소득세 10만6천… |
| 24~30초 | 사이트 주소 | 내 연봉도 계산해 보기 → 프로필 링크 |

**캡션:** 2026년 국민연금 올라서 작년보다 더 빠져요 😢 #연봉실수령액 #월급 #직장인

## 2. "사장님, 11월 세금 고지서 왔죠?"
| 시간 | 화면 | 자막 |
|---|---|---|
| 0~3초 | 달력 11월 30일 | 사장님, 11월 30일 세금 마감이에요 |
| 3~10초 | 가이드 페이지 D-day | 종합소득세 중간예납, 50만원 미만이면 안 내도 돼요 |
| 10~20초 | 종소세 계산기에 매출·경비 입력 | 내년 5월엔 얼마 나올지 미리 계산 |
| 20~27초 | 절세 팁 박스 | 노란우산 넣으면 99만원 절약?! (매출 8천·경비 5천 예시) |
| 27~30초 | 사이트 주소 | 무료 · 가입 없음 → 프로필 링크 |

**캡션:** 장사도 바쁜데 세금까지… 미리 알고 준비해요 #자영업자 #종합소득세 #사장님
