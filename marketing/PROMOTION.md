# 세금 도우미 홍보 플랜

광고 수익 = **방문자 수 × 방문자당 수익**입니다. 사이트를 만든 다음에는 방문자를 늘리는 일이 전부입니다.

## 0. 먼저: 방문자 수를 볼 수 있게 하기
방문자를 세지 않으면 무엇이 효과가 있는지 알 수 없습니다.
- **Google Analytics** (analytics.google.com): 속성을 만들고 `G-`로 시작하는 측정 ID를 Claude에게 알려주세요. 모든 페이지에 넣어 드립니다.
- 네이버 애널리틱스(analytics.naver.com)도 무료입니다. 사이트 ID를 알려주시면 함께 넣어 드립니다.

## 1. 검색엔진 등록 (무료, 효과가 가장 오래감)
한국에서는 **네이버**와 **구글**을 둘 다 해야 합니다.

| 어디 | 할 일 |
|---|---|
| 네이버 서치어드바이저 (searchadvisor.naver.com) | 사이트 등록 → "HTML 태그" 방식 선택 → 나오는 `<meta name="naver-site-verification" ...>` 코드를 Claude에게 전달 → 반영 후 "소유확인" → 요청 메뉴에서 **사이트맵 제출** (`sitemap.xml`) |
| Google Search Console (search.google.com/search-console) | "URL 접두어"로 사이트 주소 입력 → "HTML 태그" 방식 → 코드를 Claude에게 전달 → 확인 → **Sitemaps**에 `sitemap.xml` 제출 |
| 다음 검색등록 (register.search.daum.net) | 사이트 주소 등록 |

- 네이버는 하위 경로(`/asax/`) 주소보다 **도메인 주소**를 등록하는 게 확실합니다. 도메인을 산 다음에 등록하세요.
- 등록 후 검색 결과에 나오기까지 보통 몇 주가 걸립니다.

## 2. 시즌을 노리기
세금 계산기는 **신고 시즌에 검색량이 몇 배로 뜁니다.**

| 시기 | 사람들이 찾는 것 | 이 사이트에서 미는 페이지 |
|---|---|---|
| 11월 | 종합소득세 중간예납 | 자영업자 종합소득세 |
| 1월 | 부가세 확정신고, 연말정산 | 부가세 납부세액, (연말정산 계산기 추가 추천) |
| 2~3월 | 연봉 협상, 이직 | 연봉별 실수령액 페이지 |
| 5월 | 종합소득세 신고 (가장 큰 시즌) | 자영업자 종소세, 3.3% 환급 |
| 7월 | 부가세 확정신고 | 부가세 납부세액 |

시즌 2~4주 전에 블로그 글과 커뮤니티 공유를 몰아서 하세요.

## 3. 커뮤니티 공유
**각 커뮤니티의 홍보 규칙을 꼭 지키세요.** 홍보 게시판이 따로 있으면 거기에만 올리고, 같은 글을 여러 곳에 도배하면 강퇴나 신고로 오히려 손해입니다. 질문 글에 실제로 도움이 되는 답을 달면서 링크를 함께 거는 게 가장 효과적입니다.

| 대상 | 어디 |
|---|---|
| 자영업자·소상공인 | 네이버 카페 "아프니까 사장이다", 지역 상인 카페, 업종별 사장님 카페 |
| 직장인 | 블라인드, 이직·연봉 관련 커뮤니티 |
| 프리랜서·알바 | 프리랜서 카페, 알바 커뮤니티 |
| 지인 | 카카오톡 단톡방 (공유 미리보기 이미지가 뜹니다) |

### 공유 문구 예시

**자영업자 카페 (질문 글에 답할 때)**
```
저도 매번 헷갈려서 계산기를 하나 만들어 봤어요.
매출이랑 경비만 넣으면 5월 종소세가 대충 얼마인지 나오고,
노란우산 넣으면 얼마 줄어드는지도 바로 보여요. 무료고 가입도 없어요.
👉 [사이트 주소]/business-tax.html
정확한 금액은 세무사님이나 홈택스로 꼭 다시 확인하세요!
```

**직장인 커뮤니티**
```
2026년 국민연금 4.75%로 오른 거 반영해서 연봉별 실수령액 정리해 봤습니다.
연봉 4000이면 월 291만원 정도네요. 내 연봉으로도 바로 계산돼요.
👉 [사이트 주소]/salary.html
```

**지인 단톡방**
```
연봉 실수령액, 3.3% 세금, 퇴직금, 부가세 계산기 만들었어 😊
써보고 불편한 거 있으면 알려줘!
👉 [사이트 주소]
```

## 4. 네이버 블로그 (네이버 검색 유입에 가장 효과적)
네이버 검색 결과에는 블로그 글이 많이 노출됩니다. 블로그에 정보 글을 쓰고 본문에 계산기 링크를 넣으세요. 한 주에 2~3개가 적당합니다.

추천 주제 (검색이 많은 순서):
1. 2026 연봉 4000 실수령액 (3000, 5000, 6000도 각각 한 편씩)
2. 2026 국민연금 인상, 내 월급에서 얼마 더 빠지나
3. 프리랜서 3.3% 종합소득세 환급 받는 법
4. 간이과세자 vs 일반과세자, 부가세 얼마나 차이 날까
5. 자영업자 노란우산공제로 종소세 줄이기

### 블로그 글 초안: 2026 연봉 4000 실수령액

```
제목: 2026년 연봉 4000만원 실수령액, 한 달에 얼마 받을까? (국민연금 인상 반영)

올해부터 국민연금 보험료율이 9%에서 9.5%로 오르면서
같은 연봉이라도 실수령액이 조금 줄었습니다.
연봉 4000만원 기준으로 정확히 얼마인지 정리해 봤어요.

■ 결론: 월 약 291만원
- 세전 월급: 3,333,333원
- 국민연금: 148,810원
- 건강보험: 112,640원
- 장기요양: 14,800원
- 고용보험: 28,200원
- 소득세 + 지방세: 약 11만 6천원
→ 실수령액: 약 2,912,000원
(비과세 식대 20만원, 부양가족 본인 1명 기준)

■ 부양가족이 있으면?
배우자나 자녀가 있으면 소득세가 줄어서 실수령액이 늘어납니다.
내 조건으로는 아래 계산기에서 바로 확인할 수 있어요.
👉 [사이트 주소]/salary-4000.html

■ 연봉별로 비교하면
- 연봉 3000만원: 월 약 224만원
- 연봉 5000만원: 월 약 355만원
- 연봉 6000만원: 월 약 418만원
전체 표 👉 [사이트 주소]/salary.html

※ 회사마다 간이세액표 적용 방식이 달라 몇천 원 차이가 날 수 있습니다.
```
위 숫자는 사이트 계산 결과와 같습니다. 다른 연봉으로 쓸 때는 해당 `salary-XXXX.html` 페이지의 숫자를 그대로 옮기면 됩니다.
