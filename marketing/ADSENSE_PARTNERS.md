# AdSense 심사 & 제휴 진행 가이드

## 1. AdSense 심사 준비 상태

| 심사에서 보는 것 | 상태 |
|---|---|
| 직접 만든 유용한 콘텐츠 (계산기 9종, 연봉별 페이지 31개, 세금 가이드) | 준비됨 |
| 쉬운 메뉴 구성, 모바일 화면 | 준비됨 |
| 개인정보처리방침 (광고 쿠키 안내 포함) | `privacy.html` 준비됨 |
| 이용약관 | `terms.html` 준비됨 |
| 사이트 소개 | `about.html` 준비됨 |
| **연락 가능한 문의처** | **이메일 주소 필요.** `assets/common.js`의 `CONTACT_EMAIL`에 넣기 |
| **본인 소유 도메인** | **필요.** 구매 후 `tools/set-domain.sh 도메인` 실행 |
| `ads.txt`와 AdSense 코드 | 넣어둠 (게시자 ID가 본인 것인지 확인 필요) |
| 꾸준한 방문자 | 홍보 시작 필요 (`PROMOTION.md`) |

### 신청 순서
1. 도메인 연결, 문의 이메일 등록을 끝냅니다.
2. 사이트가 새 도메인에서 잘 열리는지 확인합니다.
3. adsense.google.com → 사이트 → 새 사이트 → 도메인 입력 → 확인 방법은 ads.txt → 검토 요청
4. 심사 기간(며칠~몇 주) 동안에는 **사이트를 크게 바꾸지 말고**, 블로그·커뮤니티로 방문자를 모읍니다.
5. 거절되면 메일에 적힌 사유("가치가 별로 없는 콘텐츠" 등)를 알려주세요. 그에 맞춰 고칩니다.

### 승인 후
- AdSense → 광고 → 광고 단위 기준 → 디스플레이 광고를 만들고 슬롯 ID(숫자)를 `assets/common.js`의 `AD_SLOT`에 넣으면, 각 페이지의 광고 자리에 광고가 들어갑니다.
- 자동 광고만 켜도 됩니다. 이 경우 `AD_SLOT`은 비워둬도 됩니다.

## 2. 제휴(어필리에이트) 진행

계산 결과 바로 아래에 "함께 보면 좋은 서비스" 자리를 만들어 두었습니다. 링크가 채워진 항목만 보이고, 비어 있으면 아무것도 나오지 않습니다. 모든 제휴 영역에는 공정위 지침에 따른 **"제휴" 표시와 수수료 안내 문구**가 자동으로 붙습니다.

### 가입할 만한 곳
| 프로그램 | 이 사이트에서 쓸 곳 | 비고 |
|---|---|---|
| 쿠팡 파트너스 (partners.coupang.com) | 사장님 가이드: 영수증 정리함, 사무용품, 세무 도서 | 가입이 쉬움. 쿠팡이 정한 대가성 문구를 반드시 표시해야 하며, 이미 넣어둠 |
| 링크프라이스 (linkprice.com) | 금융·서비스 가입형 광고 | 광고주별로 승인이 필요할 수 있음 |
| 텐핑 (tenping.kr) | 금융·보험·서비스 상담 신청형 광고 | 상담 신청 1건당 수익 |
| 세무·회계 서비스 회사의 자체 제휴 | 종합소득세·부가세 계산 결과 아래 | 각 회사 홈페이지의 "제휴 문의"로 직접 제안 |

### 링크 넣는 방법
`assets/partners.js`를 열어서 원하는 항목의 `url: ""`에 받은 링크를 붙여넣으면 끝입니다. 링크를 Claude에게 보내주셔도 됩니다.

### 지켜야 할 것
- 고금리 대출, 도박성, 과장 광고 상품은 싣지 마세요. AdSense 정책 위반이 될 수 있고 사이트 신뢰도도 떨어집니다.
- 계산 결과를 특정 상품으로 유도하도록 바꾸지 마세요. 계산은 항상 중립적으로 두어야 합니다.

## 3. 제휴 제안 받기
`contact.html`에 광고·제휴 제안 안내가 있습니다. 방문자가 늘면(월 수천 명 이상) 세무·회계 서비스 회사에 직접 제안 메일을 보내볼 만합니다. 제안 메일 초안이 필요하면 Claude에게 요청하세요.
