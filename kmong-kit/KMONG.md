# 크몽 상품 등록 문구

카테고리: **IT·프로그래밍 → 홈페이지 신규 제작** (또는 랜딩페이지)

## 제목 (30자 내외, 하나 고르기)

- 동네 가게 홈페이지 하루 만에 완성해 드립니다
- 카페 학원 미용실 홈페이지, 모바일 최적화로 빠르게
- 월 유지비 0원, 우리 가게 홈페이지 제작해 드립니다

## 검색 태그

`홈페이지제작` `랜딩페이지` `반응형웹` `소상공인홈페이지` `카페홈페이지` `학원홈페이지` `미용실홈페이지` `원페이지`

## 서비스 설명

```
✔ 이런 분께 추천합니다
- 네이버 플레이스나 인스타만 있고 홈페이지가 없는 가게
- 홈페이지 견적이 수백만 원이라 망설였던 사장님
- 메뉴·가격·위치를 링크 하나로 깔끔하게 보여주고 싶은 분

✔ 이렇게 만들어 드립니다
- 휴대폰에서 보기 좋은 반응형 디자인
- 메뉴판/가격표, 영업시간, 오시는 길(지도), 사진 갤러리
- 카카오톡·전화·네이버 예약 버튼 연결
- 검색 노출 기본 세팅 (제목, 설명, 공유 미리보기)
- 무료 호스팅 → 월 유지비 0원 (도메인은 선택, 연 1~2만원)

✔ 샘플 사이트 (직접 눌러보세요)
- 카페: [배포 주소]/samples/cafe.html
- 학원: [배포 주소]/samples/academy.html
- 미용실: [배포 주소]/samples/salon.html

✔ 진행 과정
1) 상담: 업종, 원하는 분위기 말씀해 주세요
2) 자료 전달: 사진, 메뉴/가격, 주소, 연락처 (문구는 제가 써드려요)
3) 시안 확인: 링크로 바로 확인하고 수정 요청
4) 오픈: 주소 연결과 네이버·인스타 링크 등록까지 안내

✔ 작업 전 꼭 메시지 주세요
업종과 필요한 내용을 먼저 말씀해 주시면 가장 맞는 패키지를 안내해 드립니다.
```

> `[배포 주소]`는 GitHub Pages 주소로 바꾸세요 (README 참고). 크몽은 외부 연락처나 외부 결제 유도를 금지하니, 샘플 링크에 개인 연락처가 노출되지 않게 하고 크몽 안에서만 결제받으세요.

**첫 주 전략:** 리뷰가 없을 때는 가격 장벽을 낮추는 게 중요합니다. 등록 직후 2~3건은 "오픈 기념 할인"으로 STANDARD를 9~10만원 정도에 받아 리뷰를 먼저 쌓는 것도 방법입니다. 다만 3일 안에 100만원이 목표라면 크몽만으로는 부족하니 `SALES.md`의 직접 영업을 함께 해야 합니다.

## FAQ

**Q. 유지비가 드나요?**
A. 무료 호스팅을 써서 월 유지비는 0원입니다. .com이나 .kr 주소를 원하시면 연 1~2만원 정도 도메인 비용만 듭니다.

**Q. 사진이나 글이 없어요.**
A. 휴대폰 사진이면 충분합니다. 소개 문구는 제가 써드립니다.

**Q. 나중에 수정할 수 있나요?**
A. 오픈 후 7일간 간단한 수정은 무료이고, 이후에는 건당 소액으로 해드립니다.
