# 3일 실행 계획

목표 100만원 = **스탠다드(30만원) 3건 + 베이직(15만원) 1건**, 또는 프리미엄 2건.
보통 연락한 가게 중 답장이 오는 건 일부이고, 실제 계약은 그중 일부입니다. 그래서 **하루에 최소 30~50곳**에 연락해야 승산이 있습니다.

## 1일차: 준비하고 연락 시작

- [ ] `index.html`에 크몽 주소 넣고 GitHub Pages로 배포 (README 참고)
- [ ] 크몽 상품 문구를 `KMONG.md` 내용으로 수정하고, 샘플 링크 추가
- [ ] 홈페이지 없는 가게 목록 만들기
  - 네이버 지도에서 "동네 이름 + 카페/학원/미용실/공방/필라테스" 검색
  - 플레이스에 **홈페이지 링크가 없거나 인스타만 있는 곳**을 고르기
  - 스프레드시트에 가게 이름 / 연락 수단 / 연락 날짜 / 답장 여부 기록
- [ ] 오후에 30곳 이상 연락 (아래 문구 사용)

## 2일차: 연락 늘리고 계약 받기

- [ ] 새로 30~50곳 더 연락, 어제 연락한 곳 중 읽고 답 없는 곳에 한 번만 다시 연락
- [ ] 관심 보인 곳에는 **그 가게 이름을 넣은 샘플을 먼저 만들어서** 보여주기 (Claude에게 요청하면 금방 만듭니다). 직접 보여주는 게 계약률이 가장 높습니다.
- [ ] 계약하면 **선금 50%**를 받고 작업 시작

## 3일차: 납품하고 잔금 받기

- [ ] 시안 보내고, 수정 반영해서 배포
- [ ] 잔금 받기
- [ ] 고객에게 크몽 리뷰나 지인 소개 부탁하기

## 연락 문구

### 인스타 DM / 카카오톡 채널

```
안녕하세요 사장님, 근처에서 작은 가게 홈페이지를 만들어 드리는 ○○입니다.
네이버 플레이스를 보니 홈페이지가 따로 없으신 것 같아 연락드렸어요.

메뉴, 가격, 위치, 예약 버튼을 휴대폰에서 보기 좋게 정리한 홈페이지를
하루 만에, 15만 원부터 만들어 드립니다. 월 유지비는 없습니다.

예시는 여기서 보실 수 있어요 👉 [배포 주소]
관심 있으시면 사장님 가게 버전으로 시안을 먼저 무료로 보여드릴게요!
```

### 다시 연락할 때 (한 번만)

```
사장님, 지난번 홈페이지 건으로 연락드렸던 ○○입니다.
혹시 몰라 사장님 가게 이름으로 간단한 시안을 만들어 봤어요 👉 [시안 링크]
마음에 드시면 이번 주 안에 바로 오픈해 드릴 수 있습니다. 아니시면 편하게 넘기셔도 됩니다 🙂
```

### 직접 찾아갈 때 (가장 효과 좋음)

샘플 사이트를 휴대폰에 띄워 보여주면서:
> "사장님 가게도 이렇게, 이 링크 하나로 메뉴랑 위치랑 예약까지 보이게 해드려요. 15만 원이고 내일 바로 보여드릴 수 있어요."

## 꼭 지킬 것

- **크몽에서 만난 고객은 반드시 크몽 안에서 결제**받으세요. 외부로 결제를 유도하면 계정이 정지됩니다.
- 직접 영업한 고객은 **본인 명의 계좌**로 받으면 됩니다. 금액과 작업 범위는 카톡으로라도 글로 남겨 두세요.
- 연락을 거절한 가게에는 다시 연락하지 마세요. 같은 내용을 한꺼번에 대량으로 보내면 스팸 신고나 계정 제한을 받을 수 있으니, 가게 이름을 넣어 한 곳씩 보내세요.
- 소득은 다음 해 5월 종합소득세 신고 대상입니다. 입금 내역을 보관해 두세요.
